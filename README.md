# 🦁 ROAR: Repository of AI-Driven Research System Runs

**A community repository for unifying and analyzing runs from AI-driven research systems.**


## What is ROAR?

AI-driven research systems (ADRS) like OpenEvolve, SkyDiscover, and GEPA each produce results in different formats, and teams operate in isolation — making it difficult to compare or learn across runs. ROAR provides a unified relational schema and parser layer that normalizes heterogeneous ADRS outputs into a common format. This enables cross-system analytics that reveal patterns in problem landscapes, search behavior, and optimization strategies that are invisible from any single system or team alone.

ROAR ships with built-in analytics pipelines for exploring pooled run data, including basin structure detection, stopping heuristic calibration, and context diversity analysis.
